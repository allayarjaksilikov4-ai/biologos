BIOWORLD — 8-sinf biologiya uchun o‘quv sayti

ISHGA TUSHIRISH
1. ZIP faylni Windows’da “Извлечь все / Extract All” orqali oddiy papkaga chiqaring.
2. VS Code’da File → Open Folder orqali ichidagi BioWorld_Pro papkasini oching.
3. index.html faylini ochib, o‘ng tugma → Open with Live Server ni tanlang.
4. index.html, style.css va script.js fayllarini bir-biridan ajratmang — ular bitta papkada turishi kerak.

FAYLLAR
- index.html: sahifa tuzilishi
- style.css: dizayn va moslashuvchan ko‘rinish
- script.js: mavzular, anatomik sxema va mini test

ESLATMA
Mavzular umumiy 8-sinf darajasidagi o‘quv mazmuni sifatida tuzilgan; ular muayyan darslikning rasmiy to‘liq nusxasi deb hisoblanmasin. Aniq mavzular ketma-ketligi maktabingizdagi biologiya darsligiga qarab farq qilishi mumkin.
Anatomiya tasviri interaktiv o‘quv sxemasi, tibbiy aniqlikdagi haqiqiy 3D model emas. Google Fonts uchun internet kerak; saytning asosiy funksiyalari lokal ishlaydi.
